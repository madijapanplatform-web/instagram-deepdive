# Analysis methodology — how to write a deep-dive that's actually insightful

The renderer is just a frame. The value is the analysis. Treat this like a creative strategist
reverse-engineering a winning ad: look at the real frames, read the real captions, do the math, and
explain *why it worked* in a way someone could copy.

## 1. Look before you write
Read the contact sheets (`sheet_story.jpg`, `sheet_hook.jpg`) and the per-cut thumbnails with the
Read tool and actually look at them. For **each cut** note: the on-screen caption (verbatim — these
tell the story), what the camera shows, and the implied viewer feeling. The first-3s sheet (4 fps) is
where you decode the hook beat by beat. Also read the scraped **caption** and **hashtags** — they
reveal the goal (e.g. a "comment X for the link" funnel) and the target.

## 2. Do the math (don't hand-wave the metrics)
- Engagement rate = (likes + comments) / views. Reels are typically ~1–3%; above that is strong.
- Like rate and comment rate separately — a high comment rate often signals an engineered comment
  funnel (keyword gating) rather than organic love.
- **Reach vs followers**: views ÷ followers. >1 means it escaped the follower base into
  Explore/recommendations — the single clearest "it went viral" signal. State the multiple ("×1.4").

## 3. Reconstruct the structure
Map cuts → narrative phases (호기심 → 관심 → 이해 → 욕구 → 결심). Identify:
- **The hook (0–3s):** what stops the scroll? Look for a *curiosity gap* (hiding the product's
  identity, a question caption), a strong visual, and the USP planted early. Explain the 80/20 truth:
  most reels live or die in the first 3 seconds, so dissect them frame by frame.
- **The pacing:** measure shot lengths. Long hook + fast info + long payoff is a deliberate rhythm;
  call out the longest (usually the hook or the climax) and shortest (usually info) shots.
- **The climax (★ P2):** the real emotional peak is often NOT the hook — for product reels it's the
  payoff/tasting/demo moment. Find it; that's where desire peaks and the CTA should sit right after.
- **Transitions:** hard cuts vs dissolves; whether captions change in lockstep with cuts.

## 4. Emotion curve & peaks
`emoPts` is a smooth 8–10 point curve of intensity over time. Place the **three peaks** on top:
P1 hook spike, P2 the true climax (`star:true`), P3 the CTA/turn. Tie each peak to a real on-screen
line. The story the curve tells should be: grab → (dip while informing) → climb to climax → convert.

## 5. Goal, target, weaknesses — be concrete and honest
- **Goal:** infer the funnel (reach → comment/DM → profile link → purchase). Use evidence from the
  caption (CTAs, keyword gating, "link in bio").
- **Target:** a one-line persona + WHO/NEED/WHEN layers + the specific emotions triggered (and the
  *mechanism* for each, e.g. "low-calorie line removes the dieter's guilt").
- **Weaknesses:** this is where most analyses chicken out. Name real risks — overpromising hooks,
  unverified claims, friction in the funnel, weak save-incentive, long purchase path. Honest critique
  is what makes the report worth reading.

## 6. Benchmarking patterns (the reusable gold)
Abstract 5–6 transferable formulas from this one video and give each an `apply` example in a
*different* niche (beauty, finance, cooking, interior…). This is what lets the user reuse the insight
on their own content.

## Quality bar
- Cite **real** on-screen text and **real** numbers; never invent metrics. If a datum isn't available
  (e.g. true retention/exit-rate is private), say the emotion curve is a qualitative estimate.
- Match every word to the frames you actually saw. Do not copy another reel's analysis.
- Write in the user's language (mirror the account's/user's language; the reference used Korean).
- Specific beats generic every time. "0.5–1.0s: the question caption opens a curiosity gap" >> "the
  hook is engaging."
